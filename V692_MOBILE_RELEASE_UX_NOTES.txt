CAMPUS//ARCHIVE V6.9.2 — MOBILE RELEASE UX

定位：
冻结 V6.9.1 人格算法，本版只做正式发布前的手机体验与结果页信息层级优化。

本版完成：
1. 答题阶段隐藏六维测量目标：不再向用户显示“学业 / 社交 / DDL / 秩序 / 探索 / 感知”等维度提示，降低作答被测试目标诱导的风险。
2. 题目提示统一为中性提示：“别选应该怎么做，选现实里最可能的第一反应。”
3. 手机答题页重构为“场景图 → 问题 → 四个选项”，隐藏多余的诊断 HUD、已完成计数和底部维度栏。
4. 进度语义明确：顶部显示当前题 Qxx/24；桌面 COMPLETED 仅表示已完成题数，不再与当前题号混淆。
5. 手机端答案按钮提升字号、点击区域和中文可读性；不再显示每个选项下方的维度 badge。
6. 结果页 CTA 重排：“分享给朋友”为唯一主按钮，“生成我的人格卡片”为第二操作，“重测”降级。
7. 结果页长中文正文改用系统中文字体；标题、数字、HUD 继续保留像素字体。
8. 手机档案参数改为单列并允许换行，修复 VARIANT / STABILITY / FILE ID 截断。
9. 关系页、深度解析页正文增大并提高行距；手机卡片间距重新收敛。
10. 电脑 2K/4K 答题区增加 1500px 内容宽度上限，场景图加宽、问题与答案限制阅读宽度，减少超宽屏空白和横向漂移。
11. EdgeOne 测试环境提示更新：临时预览地址在微信出现 401 时，引导复制完整链接到系统浏览器；明确这是预览鉴权限制，不是测试程序故障。
12. 浏览器标题、页脚、海报版本号统一为 V6.9.2。

重要：
- V6.9.1 的 QUESTIONS、ARCHETYPES、SCORE_CALIBRATION、modelDistance / similarity 算法逻辑未改。
- EdgeOne 预览链接的微信 401 发生在网页加载之前，前端代码无法绕过。正式微信直开需要绑定长期自定义域名（含中国大陆节点时按平台要求完成备案）。
- EdgeOne 已连接 GitHub main；本版上传并 Commit 到 campus-archive 后应自动触发新部署。
